# Security Guide

## Your job

Keep VRChat instances safe during events so hosts can focus on hosting. You're the shield, not the spotlight.

## Before the event

- Confirm with the host: instance type (group / invite+), expected attendance, any known troublemakers.
- Arrive early. Be in the instance before guests.
- Know your tools: kick, ban, block, mute — and the instance settings.

## During the event

- **Watch for crashers, trolls, and griefers** — avatar crashers, loud mic spam, NSFW avatars in SFW spaces.
- **Act fast, act quiet.** Remove the problem with minimal disruption. Don't announce it; the event continues.
- **De-escalate first** when it's ambiguous — some people are just clueless, not malicious. One warning, then removal.
- **Protect vulnerable members.** In a little space community, some attendees are in a headspace where confrontation is genuinely distressing. Handle removals away from the group when possible.
- **Stay in contact** with the host (whisper/DM) — they need to know if something happened, but not mid-activity.

## After the event

- Report removals to the mod team: who, what they did, what you did, timestamps.
- Flag repeat offenders for instance bans or group bans.

## You are not a mod

Security covers the VRChat instance during events. Discord moderation, tickets, and bans are the **Server Staff** team's job — hand it off with a clear report.
