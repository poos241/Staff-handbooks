# Host Guide

## Before the event

- [ ] Pick the event type, world, and time. Check for conflicts with other events.
- [ ] Post the announcement — > **TODO:** where (announcement channel? event bot?) and how far in advance.
- [ ] Confirm security coverage with the security team.
- [ ] Prepare the world: test the instance, check portals, set group/invite settings.
- [ ] Have a co-host or backup if possible — don't single-point-of-failure yourself.

## During the event

- **Open on time.** Post the instance link/invite in the event channel.
- **Set the tone early.** Welcome people, explain what's happening, keep energy warm and inclusive.
- **Watch the room.** You're the vibe-setter — if energy dips, switch activities; if someone's uncomfortable, check in.
- **Coordinate with security.** They handle crashers and trolls; you keep the event flowing. Don't stop the event to deal with disruption — let security handle it.
- **Pace yourself.** Long events need breaks. It's okay to hand off to your co-host.

## After the event

- [ ] Thank everyone and close the instance.
- [ ] Drop a quick recap in the event channel (attendance, highlights, issues).
- [ ] Report any incidents to the mod team with names, timestamps, and what happened.
- [ ] Rest. Hosting is work — take care of yourself too.
