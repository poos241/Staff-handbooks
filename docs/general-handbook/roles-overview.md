## Leadership

| Role | Responsibility |
|---|---|
| Community Owner(s) | Final say on everything. Handles staff discipline and big decisions. |
| Head Mod / Admin | Runs day-to-day operations, manages the mod team. |

## Server Staff

| Role | Responsibility |
|---|---|
| Server Mod | Keeps Discord safe and welcoming. Enforces rules, handles tickets and reports. |
| Trial Mod | New mods in training. Same duties as mods but with a mentor and limited powers. See the [Trial Mod Program](../server-staff/trial-mod-program.md). |

## Event Staff

| Role | Responsibility |
|---|---|
| Event Host | Plans and runs events in VRChat (and Discord). Sets the vibe, manages the schedule. |
| Event Security | Keeps VRChat instances safe during events. Handles crashers, trolls, and disruptions. |

## Server IT

| Role | Responsibility |
|---|---|
| Server IT | Manages bots, roles, channels, permissions, and integrations. First call for anything technical. |

## How the teams work together

- **Mods** handle the Discord server day-to-day.
- **Hosts** run events; **security** protects the VRChat instance while they do.
- **IT** supports everyone — if a bot breaks mid-event, IT is who you ping.
- When in doubt about whose job something is, ask in the staff channel rather than guessing.
