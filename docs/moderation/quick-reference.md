# Quick Reference

## Important to Be Aware Of

- **Ping users in the message you send after adding them** to a ticket, so they're sure to see it and know the ticket exists.
- **Giving a user a punishment will DM them** — they get notified automatically.

## Cheat Sheet

| Situation | Action |
|---|---|
| You spot rule-breaking | Handle it if you're able; otherwise contact another mod immediately |
| Taking any mod action | Must be justified, reasonable, and fit the situation |
| Not enough evidence / reasonable doubt | Do **not** moderate — unfair judgment helps no one |
| Issue involves another staff member | Don't touch it — get the appropriate supervisor's consent first |
| Running a mod command | Use `#mod-commands` or the relevant ticket, always with a reason |
| User asks for their evidence | Show it — unless sharing risks another user's safety (then get their permission first) |
| Closing a ticket | Get the opener's permission, state what happened and the action taken |
| Ban a troll | Delete their server invites too (**Server Settings → Invites**) |
| Bots/server misbehaving | Add it to `#to-do-list` if it's not already there |
| Timeout issued | Open a ticket immediately → inform → keep open → confirm end → request acknowledgment |
| No acknowledgment after timeout/warning | Wait 2 days → ping once → 24h more → may escalate one category |
| Announcing a ban | OK to announce; keep sensitive reasons minimal |
| Logging | Screenshots → `#evidence-for-logs` with user IDs; banned IDs in the reporting ticket |
