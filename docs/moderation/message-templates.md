# Message Templates

Copy-paste templates for common moderator messages. Hit the copy button on any block, paste it into Discord, and fill in the bracketed parts. Keep the tone as written — it's deliberate.

:::tip Personalize before sending

Always replace `[bracketed]` placeholders and read the message once before you send it. A template with leftover brackets looks careless.
:::

## Timeout notification (ticket)

Send immediately after issuing a timeout, in the ticket you opened with the user.

```
Hi [username], you've been timed out for [duration] because [reason].

Your timeout ends at [date/time with timezone]. During this time, please
take a moment to re-read the server rules.

This ticket will stay open until the timeout ends. If you have questions,
you can ask them here.
```

## Warning — acknowledgment request

Required whenever you issue a warning or timeout: state the action and ask for acknowledgment.

```
You are receiving an [informal/formal] warning for [specific rule broken].

Please reply to acknowledge that you've read this and understand the
rules going forward.
```

## Follow-up ping (no acknowledgment)

Send once, 2 days after the warning/timeout, if the user never acknowledged.

```
Hi [username], following up on the [warning/timeout] issued on [date].
Please acknowledge the message above so we know you've seen it.

If we don't hear back within 24 hours, the punishment may be escalated
to the next category per our procedures.
```

## Ban announcement (public)

Appropriate level of detail — names the action, keeps the reason general.

```
User [username] has been banned due to repeated rule violations.
```

For a clear, community-relevant reason (hate speech, trolling, repeated rule-breaking), you may state it plainly. For sensitive reasons, keep it minimal — never include details that could identify or retraumatize a victim.

## Privacy deflection

When a member asks about someone else's punishment.

```
We don't share details of punishments to protect everyone's privacy.
Thanks for understanding.
```

## Community safety reminder

For incidents that may affect the community's sense of safety. No names.

```
We want to remind everyone to report any behavior that makes you
uncomfortable. Safety is our top priority.
```

## Ticket closing reason

Always state what happened and the action taken when closing a ticket.

```
Reported user warned for [violation]. Evidence logged in #evidence-for-logs.
```

```
Ticket resolved: [brief summary]. No further action needed.
```

:::warning Keep punishments private

Templates 1–3 and 7 go in **tickets or DMs only**. Only the ban announcement, privacy deflection, and safety reminder are for public channels. See [Informing Members of Punishments](./informing-members) for the full guidelines.
:::
