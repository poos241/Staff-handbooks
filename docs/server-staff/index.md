# Server Staff Handbook

For **moderators** and **trial mods** — the team that keeps the Discord server safe and welcoming.

## Your job in one sentence

Keep the server comfortable: enforce the rules fairly, help members who need it, and escalate what you can't handle alone.

- [Moderator Duties](moderator-duties.md) — what you're responsible for day-to-day.
- [Trial Mod Program](trial-mod-program.md) — how trial mods are trained and promoted.
- [Moderation Procedures](moderation-procedures.md) — step-by-step for warnings, mutes, kicks, and bans.
