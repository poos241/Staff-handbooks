# Moderator Duties

## Daily responsibilities

- **Watch the channels.** You don't need to read everything, but stay aware — especially during busy hours.
- **Handle reports and tickets.** Respond promptly; even a "looking into it" reply matters.
- **Enforce the rules evenly.** See [Moderation Procedures](moderation-procedures.md) for the step-by-step.
- **Welcome newcomers.** A friendly hello from a mod sets the tone for the whole server.
- **Keep the vibe.** Little space is about comfort. Gently redirect conversations that get too heated, cynical, or off-theme.

## What mods don't do

- Change server settings, roles, or channels — that's **Server IT**.
- Run events — that's **Event Hosts** (you can still attend and help!).
- Handle VRChat instance security — that's **Event Security**.
