This is the changelog for the staff handbooks. Whenever something changes — a rule update, a new procedure, a corrected command — it'll get a short post here so nobody has to re-read the whole handbook to stay current.

## What changed recently

- **New: Moderation Handbook section** — the full Little Haven moderation guide is now on the site: rules and guidelines, mod commands, procedures, punishment communication, and a quick-reference cheat sheet.
- **Dark mode** is now the default theme (you can still toggle light mode).
- **Search bar** added to the navbar — searches every page instantly.
- **"Edit this page" links** on every docs page for quick fixes by the team.

If you spot something outdated or wrong, use the **Suggest a change** link in the footer, or hit **Edit this page** if you have repo access.
